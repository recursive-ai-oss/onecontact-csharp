# Tier 2 contact blocks (`blocks-tier2-v1`)

Generated by `tools/data/blocks` (`render-tier2`, tool version `blocks-3`, seed 20261108, 400,000 ids tried, 20,138 reserved and never rendered, 0 span failures; split rule in the set's `manifest.json`). Built from `names-tier2-v1` and a stride sample of 6,000 training and 600 development lines of each Tier 2 address file (sources and licences in `address-tier2-a.md`, `-b.md`, `-c.md`), with English page text written for the generator and the Tier 2 labels, titles and navigation words appended. Phone numbers are generated from libphonenumber example numbers (Apache-2.0 data) with random tail digits, valid for the address's region. Free-mail and country-code domains come from lists of ours. No external text, no Common Crawl, no OpenStreetMap, no hosted-model labels. Development blocks draw only from development files; reserved ids are never rendered.
